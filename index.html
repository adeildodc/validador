Como Usar seu Próprio Firebase no Projeto

Guia passo a passo para conectar o banco de dados e publicar no seu site

1 Acessar o Firebase Console

O Firebase é um serviço gratuito do Google. Para criar seu banco de dados:

  1. Acesse o site oficial: console.firebase.google.com
  2. Faça login com sua conta do Google.
  3. Clique no botão "Adicionar projeto".
  4. Dê um nome para o seu projeto e clique em Continuar até concluir a criação.

2 Ativar Firestore Database & Autenticação Anônima

A) Ativar o Banco de Dados (Firestore):

No menu lateral, vá em Build → Firestore Database → clique em "Criar banco de dados" em modo de teste.

B) Ativar Autenticação Anônima:

Vá em Build → Authentication → clique em Anônimo e marque Ativar.

3 Configurar Regras de Segurança do Firestore 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

4 Inserir Credenciais no Seu HTML

Insira a variável firebaseConfig na tag <script type="module"> no seu arquivo HTML.

Cadastrar em Banco de Dados (Firebase)

Grave dados em tempo real na sua lista de produtos

Para registrar ou salvar dados no banco de dados Firebase Firestore, utilizamos as funções addDoc e setDoc.
